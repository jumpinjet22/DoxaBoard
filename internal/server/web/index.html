Broadcasts

A broadcast is where a service goes: one or more outputs (Vimeo, YouTube, Facebook, any RTMP/SRT ingest). Stream keys are stored encrypted.

Broadcast

Outputs

Copy the Stream URL and Stream key from your platform's live settings. Common URLs: YouTube rtmp://a.rtmp.youtube.com/live2, Facebook rtmps://live-api-s.facebook.com:443/rtmp/, Vimeo: shown in the event's stream settings.

Content sources

Announcements and photos from RSS feeds, JSON feeds and folders. Add a source here, then pick it in a profile.

Cloud folders

Photos from OneDrive, Google Drive or Dropbox. Each folder you connect becomes a photo album that stays in step with the cloud folder; pick the album in a profile.

Connect a cloud folder

Where are the photos?

  1. Open the sign-in page
    It opens in a new tab. Sign in and approve access. The consent page says "rclone", the tool DoxaBoard uses; DoxaBoard only reads your files.
  2. Your browser then lands on a page that won't load ("This site can't be reached"), with an address starting http://localhost:53682/ or http://127.0.0.1:53682/. That's expected.

Pick the folder with the photos. Only pictures directly inside it are used.

Pictures removed from the cloud folder are removed from the album too.
